# Tests

Tests prove the bridge's contracts at the layer that can observe them. Unit tests sit next to their source files and cover pure policy: classification, the request lifecycle, wake decisions, rendering and secret checks, `ts` comparison, caller resolution, and presenters. The suites here cover what only a running bridge can show.

- `integration/` runs the bridge against protocol fakes of Socket Mode, the Slack Web API, and Toy Box, with no network, ephemeral ports, and temp folders. A suite spawns the real bridge process when it proves startup, shutdown or wiring, and drives the bridge's server modules in-process when it injects a clock or short timings. A spawned bridge finds the fake Toy Box through `TOY_BOX_URL` and takes shorter waits from `TOY_BOX_SLACK_WAKE_TIMINGS`, a JSON object of the wake timings to change, in milliseconds. `bun test` runs it with the unit tests.
- `e2e/` runs the built Toy Box with a real Copilot lead on claude-sonnet-5, the real bridge and CLI, and fake Slack. Every run spends model credits, so it runs only with `TOY_BOX_SLACK_E2E=1`, and one run at a time, because Toy Box takes port 3199.
- `fakes/` holds the protocol-faithful fakes both suites share. A fake reproduces what the real service does on the wire, including its failures, and nothing more.

An end-to-end run starts Toy Box under a temp `HOME`, so its database, sessions, skills and Copilot state never touch the owner's. Before Toy Box starts, the CLI under test goes on its `PATH` and `install-skill` puts the skill in that `HOME`, as an owner's install would. It drops the variables agent shells set, which point at the owner's Toy Box, session and credentials, and its Copilot CLI signs in with the token from `gh auth token`, which goes only into Toy Box's environment. Set `TOY_BOX_BINARY` to run a binary other than the toy-box checkout's. The bridge runs `serve` under the same `HOME` against fake Slack, so the lead's commands reach it, and it wakes the lead through that Toy Box a second after a request changes. The owner's setup is real too: the harness sets a passphrase, then links the channel and allows Alice with the CLI at a terminal, typing the passphrase on stdin. The lead adds the skill's routines with their prompts as written, so the scenarios prove the prompts leads get. A test channel's purpose rules out members, tasks and wakes its lead schedules, and a test wakes the lead only as the owner, with a routine run or through the bridge, once its last turn has settled. Assert what the lead did through `bridge.db`, the fakes and its presence, never its words. A failed run keeps its folder, without the Copilot CLI's unpacked caches, and names the lead's transcript and the tail of Toy Box's and the bridge's logs.

The live checklist runs by hand in the real test workspace with the test app's tokens, and its results go to the Toy Box channel.

`startFakeSlack()` in `fakes/slack` binds only to an ephemeral loopback port and exposes its `/api/` URL and fake bot and app tokens. Seed channels, people, membership and messages through its controls. Seeding changes stored state only, so drive incoming Socket Mode events and interactions explicitly. Web API posts, edits and deletes do emit events when a socket is connected. Reply deletion emits its deletion followed by root bookkeeping, retaining the root's existing edit version. Editing a root first updates its broadcasts' embedded root copies without editing those broadcasts. Acks, calls, connections and deliveries remain available for assertions, and cleanup fails on unknown methods, arguments or acks. Contract tests exercise both real Slack SDK clients. `live-shapes.json` records a keys-and-types projection captured on 2026-10-28, and `live.test.ts` checks that transcript and its ordering without credentials.

Drive Socket Mode redelivery explicitly with `redeliver`, since Slack documents no fixed retry schedule. `failNext` queues a fault for one method: a platform error, HTTP status, `Retry-After`, accepted write followed by an error, a successful post without metadata, a requested reply posted as a new root (`misplacedReply`, which can also lose its response), or an accepted operation whose response is lost. Disable SDK retries when asserting a single attempt. Use `emptyNextPage` for a cursor-bearing empty page and the injected clock for timestamps and status expiry. The emoji catalog starts with `eyes`, `white_check_mark` and `thumbsup`; `emojiNames` adds fixture-specific names, while an unknown name returns `invalid_name`. The fake models the bridge's supported API subset, not Slack's automatic rate-limit schedule, reply-user sampling or all message rendering. Time bounds are explicit, with no implicit current-time cutoff.

Give every test its own data folder and close every database it opens.
